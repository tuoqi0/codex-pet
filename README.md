# Codex Pet

Codex Pet 是一款桌面伙伴，包含原创龙娘和可选的 Q 版白龙。两个角色可以分别拖动，共享对话、任务和额度面板。坐姿龙娘参考了用户提供的形象，可以眨眼、打招呼、开心、喝茶和在工作时阅读。她的左右翅膀分层摆动，尾巴保持原姿态；翼层按桌宠尺寸制作，发丝与尾刺交界仍可能出现细小边缘瑕疵；拖动时角色会随指针倾斜，松手后逐渐回稳。巡游功能移动的是整个角色。

## 安装或升级

运行 `./build-deb.sh` 构建，然后安装生成的包。例如，若生成的版本是 2.25.0：

```sh
sudo apt install ./dist/codex-pet_2.25.0_all.deb
```

安装其他版本时，请将命令中的文件名改为 `dist` 目录中实际生成的文件名。启动新版前，请通过旧桌宠的右键菜单退出旧进程，然后从应用菜单打开 **Codex Pet**，或在终端运行 `codex-pet`。安装包依赖 PyQt5、Pillow、Requests、PyJWT 和 cryptography，由 apt 安装这些依赖。

第三方 Q 版角色素材不会放入安装包或 Git 仓库。将用户提供的压缩包放在当前目录后，可执行一次导入：

```sh
codex-pet-import ./codex-pet.tar.xz
```

如果压缩包不在当前目录，请将参数替换为该文件的实际路径。导入程序只会将角色的 WebP 文件、素材清单和来源信息写入 `${XDG_DATA_HOME:-$HOME/.local/share}/codex-pet/bailong`，不会覆盖已有目录。导入后请重启桌宠。素材缺失或不可用时，龙娘仍可运行，终端会显示原因。

## 角色互动

- 单击任意角色可打招呼；双击打开浮动面板，查看 Codex 额度，并进入聊天、计划、任务或陪伴设置。拖动可移动角色，松开龙娘时她会轻轻落下并回稳；空闲时她也会挥手。Q 版角色在拖动和落地时播放相应动作，动画时长和对齐方式来自素材清单。播放器同时只保留一个 Q 版动画源和一张显示帧；WebP 解码器可能使用额外工作内存。
- 右键任意角色可选择 **一起互动**，邀请角色一起喝茶、一起小憩、给你鼓励或开心一下；任务进行时保持工作动作。白龙会在长任务期间偶尔切换工作动画，这些动作仅用于表现陪伴，不代表具体工具活动。也可以打开共享面板、查看额度、调整该角色大小、隐藏或恢复另一角色，或退出。最后一个可见角色不能隐藏，以便继续使用控件。
- 龙娘支持可选的桌面巡游；Q 版的工作、完成和额度动作会响应面板事件。在 X11 下，当两个角色可见、位置接近且处于空闲状态时，会轮流发起简短对话；用户向其中一个角色打招呼时，另一个也可以回应。Wayland 无法可靠获取窗口绝对位置，因此关闭基于距离的自动互动。安静时间和暂停提醒会抑制主动消息，但点击角色仍可获得回应。
- 用户更改后，窗口大小、显示状态、巡游状态及 X11 位置会保存在本机。Wayland 由桌面合成器决定位置，不保存坐标。

陪伴设置提供休息、喝水、用餐和问候提醒，以及安静时间和暂停一小时功能。提醒根据桌宠运行时间和本地时钟计算，不监控活动，也不知道用户是否正在工作、喝水或用餐。天气默认关闭，需要在设置中主动搜索并选择城市后才会查询。天气数据来自 Open-Meteo，界面显示来源和模型时间；应用不会自动定位。浮动面板提供手动刷新天气的入口。运行期间每 15 分钟刷新天气模型，休眠唤醒或所选地点跨日后及时刷新，失败后约 5 分钟重试；模型时间并非实况观测时间。可在陪伴设置开启或关闭明日提醒：所选地点时区下，明日最高温比今日升高或降低至少 5°C、预报有雨、雪或雾，以及最大阵风达到 62 公里/小时会提示；预报可能变化。这些是模型预报提醒，可能与实际天气不同。每次运行中同一地点、日期和类型只提醒一次；安静时间、暂停、忙碌或隐藏角色时延后提醒，过期或查询失败的数据不会提醒。安静时间不会停止天气数据刷新。

透明窗口需要桌面合成器。在支持 XShape 的 X11 环境中，角色透明区域可以让点击穿透，角色本身仍可互动；其他环境会回退到普通窗口行为。窗口管理器也可能忽略置顶提示。在原生 Wayland 下，自动巡游关闭，拖动依赖合成器提供的窗口移动功能；其可用性和窗口位置取决于所用桌面环境。

## 对话、计划、任务与用量

通过任一角色的右键菜单打开 **对话与任务** 或 **查看额度**。三种模式分别使用以下方式：

- **普通对话**：使用本应用的 Sign in with ChatGPT 授权，流式发送文本请求，不使用本地工具。
- **计划**：使用同一授权，通过 Codex App Server 的 Plan 模式和只读沙箱运行；请先选择工作目录。计划服务使用独立配置目录，关闭外部集成。
- **任务**：使用已登录的 Codex ChatGPT 账户，要求选择工作目录，并显示受支持的审批请求。API key 登录会被拒绝。

点击 **登录 ChatGPT**，在浏览器中授权本应用。凭据保存在 `~/.config/codex-pet/`，文件权限仅允许所有者访问，与 Codex 自身凭据分开。若双方都返回邮箱，应用会比较邮箱并拒绝不匹配的账户；缺少邮箱或无法验证工作区时会明确提示，不会视为已验证匹配。面板列出各渠道返回的模型，并提供 Codex 任务模型支持的推理强度。

在任务模式下，**选择 Codex 对话**会按需列出本机 Codex 会话。选择后可以读取消息；**刷新已选对话**会获取后续消息，不发送任务，也不替换尚未发送的草稿。继续任务前，需要明确选择本次权限；应用会检查返回的沙箱和审批策略，不推断原会话权限。请避免两个客户端同时操作同一会话。ChatGPT 授权不提供 ChatGPT 网站的对话历史，因此普通对话不能同步该历史；普通对话、计划和任务各自保留上下文。新建任务启动后会自动选中相应会话，自动跟随只在面板显示且空闲时约每 30 秒检查已选会话，可以在面板中关闭。继续该会话前仍须明确选择本次权限。

助手消息支持 Markdown 格式和等宽代码块；历史比较与流式拼接保留原始文本，用户消息保持原文。文件变更审批会显示同一会话、轮次和项目中收到的完整差异；命令审批会显示关联的命令和工作目录。详情缺失、超限或在确认期间变化时，桌宠不会批准；请拒绝本次请求，再在 Codex 中重新执行并检查。终端输入审批仅在本机运行的 Codex 程序与已验证版本完全一致时开放；桌宠显示请求中的完整输入和转义字符，确认前请检查内容。未知版本、详情缺失或超限时不会提供允许按钮。终端状态可能已变化，检查输入后仍应谨慎决定。

默认回复语言为简体中文；当前消息明确指定的其他语言优先，代码、引用和名称保留原文。计划和任务模式每轮会将这一偏好作为单独的用户级文本项发送，并显示在共享的 Codex 历史中；它不会替换会话的开发者指令。

通过 **图片**可以为一条消息附加最多四张用户明确选取的静态 PNG、JPEG、WebP 或 GIF 图片。单张图片上限为 10 MiB，每次请求总上限为 20 MiB。只有提交消息时才会上传图片，所选模型和账户必须支持图片输入。普通对话将当前对话和图片保留在内存中，并在后续请求中再次发送，直到开始新对话或退出应用。计划和任务使用私有临时图片副本，请求结束后删除。

三种渠道均使用 ChatGPT 计划访问，不会静默切换到个人 API key。普通对话和计划通过 Sign in with ChatGPT 的套餐授权发送合资格请求，其用量计入与 ChatGPT Work、Codex 共享的套餐用量，并受账户和应用限额约束；应用限额是上限，不是独立额度。套餐用量耗尽后，能否使用已购买的 ChatGPT 点数取决于账户资格、应用限额及用户是否允许应用使用点数等设置，具体以 ChatGPT 设置为准。请参阅 [OpenAI 的 Sign in with ChatGPT 用量说明](https://learn.chatgpt.com/docs/sign-in-with-chatgpt)。任务使用已登录 Codex 账户的套餐用量；Codex 额度只在 App Server 返回时显示，用量设置链接会打开 ChatGPT 的设置页面。授权计划渠道受 OpenAI 的资格和预览限制约束，授权不提供 ChatGPT 对话历史。

## VS Code 侧栏开场

开场补丁需要手动启用，安装桌宠不会自动修改 VS Code 扩展。它只适配经过校验的 `openai.chatgpt` 26.1007.21434 版本；扩展更新或文件已修改时会拒绝操作。请先退出 VS Code，然后执行：

```sh
codex-pet-opening install "$HOME/.vscode/extensions/openai.chatgpt-26.1007.21434-linux-x64"
```

扩展安装目录不同时，请按实际位置替换最后的路径。从源码运行可用 `python3 opening/patch.py install 扩展目录`。补丁会备份两个原文件、校验原文件和资源的 SHA-256，在侧栏打开或重新显示时播放，并支持点击或 Esc 跳过以及系统的减少动态效果设置。

开场包含龙娘眨眼、招手、翅膀动作和光效，尾巴保持静止。首次加载时会先播放光效并等待角色图集解码，因此总时长可能增加；点击或按 Esc 可随时跳过。如果已经安装过旧版补丁，可在退出 VS Code 后升级：

```sh
codex-pet-opening upgrade "$HOME/.vscode/extensions/openai.chatgpt-26.1007.21434-linux-x64"
```

升级先校验并撤销旧补丁，再安装新版；如果新版安装失败，扩展会保持恢复后的原始状态。

撤销时先退出 VS Code，然后执行：

```sh
codex-pet-opening remove "$HOME/.vscode/extensions/openai.chatgpt-26.1007.21434-linux-x64"
```

遇到安装或撤销中断，可以再次执行同一 `remove` 命令恢复：如果文件或素材已被其他程序修改，脚本会保留它们并拒绝覆盖。更新扩展前及卸载本软件前请先撤销补丁；扩展更新或移除旧版本后，原版本目录可能不再存在。

## 独立桌面客户端开场

安装桌宠不会自动更改桌面入口。确认已安装官方 ChatGPT 桌面客户端后，可以选择启用：

```sh
codex-pet-desktop-opening install
```

该命令在当前用户的数据目录创建同名应用入口，保留官方入口的图标、文件类型和 URL 参数，启动的仍是官方客户端。若用户已有同名入口，或官方入口格式发生变化，命令会拒绝修改；不会覆盖用户自己的配置。此开场仅对应用菜单等使用该桌面入口的启动生效，直接执行客户端命令不经过该入口。

开场包含龙娘眨眼、招手、翅膀动作和光效，尾巴保持静止。开场固定播放约 3.65 秒，不会检测客户端窗口是否已经就绪；可以点击画面或按 Esc 提前关闭。若客户端启动较慢，开场结束后可能短暂显示桌面。卸载桌宠后如果还没有撤销该入口，它会回退到直接启动官方客户端。要移除用户入口、恢复使用系统入口，执行：

```sh
codex-pet-desktop-opening remove
```

程序会校验入口内容，若入口被修改则拒绝删除；安装中断后也可以运行 `remove` 清理记录。建议卸载桌宠前先撤销入口。

## 开发与测试

运行 `/usr/bin/python3 src/codex_pet.py` 启动桌宠。运行测试：

```sh
/usr/bin/python3 -m unittest discover -s tests -v
node tests/test_opening_animation.cjs
QT_QPA_PLATFORM=offscreen /usr/bin/python3 src/codex_pet.py --quit-after-ms 4000
```

`assets/` 中生成的坐姿龙娘 PNG 姿势包含在安装包内。用户自行导入的 Q 版素材保留在安装包之外，并遵守其原有许可。
